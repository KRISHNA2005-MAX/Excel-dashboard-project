# 📊 Excel Sales Performance Dashboard

## 📌 Project Overview

The **Excel Sales Performance Dashboard** is an interactive data analytics project developed using Microsoft Excel to analyze and visualize sales performance across different cities and sales executives.

The main objective of this project is to track total sales, evaluate target achievement, compare individual performance, and identify sales executives who are meeting or falling short of their sales targets. The dashboard provides meaningful insights through charts, tables, and interactive city filters to support data-driven decision-making.

## 🛠️ Tech Stack

- **Microsoft Excel** – Dashboard development and data analysis
- **Pivot Tables** – Sales summarization and performance analysis
- **Charts & Visualizations** – Bar chart, pie chart, and line chart
- **Excel Filters / Slicers** – Interactive city-based analysis
- **Excel Formulas** – Calculations and sales target performance metrics

## 📂 Data Source

The project uses sales performance data containing information about cities, sales executives, total sales, and target achievement.

**Key data fields include:**
- City
- Sales Executive
- Total Sales
- Target Hit Percentage
- Away From Target Percentage

*Note: The dashboard is based on the dataset used for this project. Replace this description with the original source or dataset link if it was obtained from an external platform.*

## ✨ Features & Highlights

- **City-Wise Filtering:** Analyze sales performance across Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, and Surat.
- **Sales Executive Performance:** Compare total sales achieved by individual sales executives.
- **Target Achievement Analysis:** Monitor the percentage of sales targets achieved by each executive.
- **Target Gap Analysis:** Identify how far sales executives are from achieving their targets.
- **Interactive Visualizations:** Use bar charts, pie charts, and line charts to present sales data clearly.
- **Performance Comparison:** Compare sales results and target-related metrics to identify high-performing executives and areas for improvement.
- **Data-Driven Insights:** Present sales information in a consolidated dashboard for easier monitoring and decision-making.
